# 📝 Styled To-Do List (freeCodeCamp Lab)

Una aplicación web de lista de tareas interactiva y estilizada desarrollada con **HTML5** y **CSS3**. Este proyecto forma parte de los laboratorios prácticos de la certificación de diseño web adaptable de **freeCodeCamp**.

---

## 🚀 Características del Proyecto

* **Maquetación estructurada:** Contenedores y listas organizadas mediante elementos semánticos de HTML.
* **Estilos interactivos en enlaces:** Práctica y aplicación de las pseudoclases CSS para distintos estados de los enlaces:
  * `:link` (Enlaces no visitados)
  * `:visited` (Enlaces visitados)
  * `:hover` (Al pasar el cursor por encima)
  * `:focus` (Contorno y enfoque de accesibilidad)
  * `:active` (Al hacer clic en el enlace)
* **Diseño moderno tipo tarjeta:** Interfaz limpia con bordes redondeados, sombras suaves y paleta de colores inspirada en interfaces modernas.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5** (Estructura de la página, inputs, etiquetas y listas de elementos)
* **CSS3** (Estilos visuales, selectores avanzados, pseudoclases y diseño adaptativo)
